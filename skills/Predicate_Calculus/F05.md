# Skill Description

The ability to understand the syntax and semantics of first-order logic. In particular, you should be able to:

* decide whether an expression is a well-formed first-order formula;
* draw the parse tree of a well-formed formula and identify the scope of each quantifier;
* distinguish variables, constants, function symbols, and predicate symbols; and
* evaluate a first-order sentence in a specified interpretation, giving a counterexample when it is False or an explanation when it is True.

# Sample Problems

## Problem 1: Syntax and scope

Consider the first-order language with unary predicate symbols $P$ and $R$, binary predicate symbol $Q$, unary function symbol $f$, and constant symbol $a$.

1. Is the following expression a well-formed formula? If it is, draw its parse tree and state the scope of each quantifier.

   $$
   \forall x\bigl((P(x)\wedge \exists y\,Q(x,y))\rightarrow R(f(x))\bigr)
   $$

2. Is $\forall x\,(P(x)\wedge)\,R(a)$ a well-formed formula? Explain.

## Problem 2: Semantics

Let the domain be $D=\{1,2,3,4\}$, and interpret $Q(x,y)$ by the following table. A `T` means $Q(x,y)$ is True.

| $Q(x,y)$ | $y=1$ | $y=2$ | $y=3$ | $y=4$ |
|:---:|:---:|:---:|:---:|:---:|
| $x=1$ | F | F | T | F |
| $x=2$ | F | T | T | T |
| $x=3$ | T | T | T | T |
| $x=4$ | F | T | F | T |

Determine whether each sentence is True or False. Give witnesses or counterexamples as appropriate.

1. $\forall x\,\exists y\,Q(x,y)$
2. $\exists y\,\forall x\,Q(x,y)$
3. $\exists x\,\forall y\,Q(x,y)$
4. $\forall x\,\neg\forall y\,Q(x,y)$

# Tutorial

## First-order languages

A first-order language specifies symbols and their arities:

* **variables**, such as $x,y,z$;
* **constant symbols**, such as $a$ or $0$;
* **function symbols**, such as a unary $f$ or a binary $+$;
* **predicate symbols**, such as a unary $P$ or a binary $Q$;
* the logical connectives $\neg,\wedge,\vee,\rightarrow,\leftrightarrow,\oplus$; and
* the quantifiers $\forall$ and $\exists$.

A **term** names an element of the domain. Variables and constants are terms, and applying an $n$-ary function symbol to $n$ terms produces another term. For example, $x$, $a$, and $f(x)$ are terms.

An atomic formula applies an $n$-ary predicate symbol to $n$ terms. For example, $P(x)$ and $Q(f(x),a)$ are atomic formulas. Larger formulas are built from atomic formulas using connectives and quantifiers.

An expression is not well formed when an operator lacks an operand, a symbol is used with the wrong number of arguments, or parentheses and quantifiers do not form a complete formula.

## Scope and parse trees

The **scope** of a quantifier is the formula it governs. In this course, use parentheses to make the scope of a quantifier and the grouping of mixed binary operators explicit. For example,

$$
\forall x\bigl(P(x)\rightarrow \exists y\,Q(x,y)\bigr)
$$

means that the universal quantifier governs the whole implication. The $x$ occurrences are bound by $\forall x$, and the $y$ occurrences are bound by $\exists y$.

A variable occurrence outside the scope of a matching quantifier is **free**. A formula with no free variables is a **sentence**. Only a sentence has a truth value determined solely by an interpretation; a formula with free variables also requires a variable assignment.

## Interpretations and models

An interpretation supplies:

* a nonempty domain $D$;
* an element of $D$ for each constant symbol;
* a function on $D$ of the correct arity for each function symbol; and
* a relation on $D$ of the correct arity for each predicate symbol.

The sentence $\forall x\,F(x)$ is True exactly when $F(d)$ is True for every $d\in D$. The sentence $\exists x\,F(x)$ is True exactly when $F(d)$ is True for at least one $d\in D$.

The order of quantifiers matters. In general,

$$
\forall x\,\exists y\,Q(x,y)
$$

allows the witness $y$ to depend on $x$, while

$$
\exists y\,\forall x\,Q(x,y)
$$

requires one value of $y$ to work for every $x$.

An interpretation is a **model** of a sentence, or of a set of sentences, when it makes every sentence True.

# Answers

## Problem 1

1. The expression is well formed. Its main connective inside the scope of $\forall x$ is $\rightarrow$. The left operand is $P(x)\wedge \exists y\,Q(x,y)$, and the right operand is $R(f(x))$. The scope of $\forall x$ is the entire implication; the scope of $\exists y$ is $Q(x,y)$.

   ![Parse tree for the well-formed F05 formula](images/F05/practice-parse-tree.svg)

2. The expression is not well formed. The connective $\wedge$ inside $P(x)\wedge$ has no right operand.

## Problem 2

1. **True.** Every row contains at least one `T`: use $y=3,2,1,2$ for $x=1,2,3,4$, respectively.
2. **False.** This would require a column containing only `T`, but every column contains at least one `F`.
3. **True.** The row $x=3$ contains only `T`, so $x=3$ is a witness.
4. **False.** At $x=3$, $Q(3,y)$ is True for every $y$, so $\neg\forall y\,Q(3,y)$ is False.
