# Skill Description

The ability to use the truth-tree method to determine whether a first-order conclusion is a logical consequence of a set of first-order premises. In particular, you should be able to:

* negate the conclusion and simplify all formulas;
* Skolemize existential quantifiers while preserving satisfiability;
* instantiate universal formulas with appropriate ground terms;
* close every branch to prove validity; and
* explain what an open branch or countermodel would show.

---

# Sample Problem

Use the truth-tree method to prove that the following inference is valid over every nonempty domain.

**Premise:**

$$
\forall x\bigl(P(x)\rightarrow\exists y\,Q(x,y)\bigr)
$$

**Conclusion:**

$$
\forall x\bigl((\forall z\,\neg Q(x,z))\rightarrow\neg P(x)\bigr)
$$

---

# Tutorial

To test whether premises $E_1,\ldots,E_n$ logically imply a conclusion $C$:

1. place all premises and $\neg C$ on one tree;
2. eliminate derived connectives and move negations inward;
3. Skolemize existential quantifiers using fresh symbols;
4. apply the [propositional truth-tree rules](../Propositional_Calculus/G01.md#truth-tree-operations); and
5. instantiate universally quantified formulas with ground terms as needed.

A **ground term** contains no variables. If the new constants are $a,b$ and the new unary function is $f$, examples include $a$, $b$, $f(a)$, and $f(f(b))$.

If there are no constants after Skolemization, introduce one fresh constant to name an element of the nonempty domain.

A universal formula may be instantiated more than once. From $\forall x\,F(x)$, any ground term $t$ permits the instance $F(t)$. Choose terms that can expose contradictions already suggested by the branch.

A branch closes when it contains an atomic formula and its exact negation, with matching terms. For example, $P(a)$ and $\neg P(b)$ alone do not close a branch. Different constant symbols need not denote different objects, but they are not automatically interchangeable.

If every branch closes, the premises together with the negated conclusion are unsatisfiable, so the argument is valid. First-order truth trees need not terminate when an argument is invalid: function symbols may generate infinitely many ground terms. A finite open branch can establish invalidity only when it supplies enough information to construct and verify a countermodel.

---

# Answer

Simplify and Skolemize the premise:

$$
\begin{aligned}
\forall x\bigl(P(x)\rightarrow\exists y\,Q(x,y)\bigr)
&\equiv \forall x\bigl(\neg P(x)\vee\exists y\,Q(x,y)\bigr)\\
&\leadsto \forall x\bigl(\neg P(x)\vee Q(x,f(x))\bigr),
\end{aligned}
$$

where $f$ is a fresh Skolem function. The symbol $\leadsto$ marks the satisfiability-preserving Skolemization step.

Negate and simplify the conclusion:

$$
\begin{aligned}
&\neg\forall x\bigl((\forall z\,\neg Q(x,z))\rightarrow\neg P(x)\bigr)\\
&\quad\equiv \exists x\,\neg\bigl((\forall z\,\neg Q(x,z))\rightarrow\neg P(x)\bigr)\\
&\quad\equiv \exists x\bigl((\forall z\,\neg Q(x,z))\wedge P(x)\bigr)\\
&\quad\leadsto (\forall z\,\neg Q(a,z))\wedge P(a),
\end{aligned}
$$

where $a$ is a fresh Skolem constant.

The tree starts with $P(a)$ and $\forall z\,\neg Q(a,z)$. Instantiate the premise at $x=a$:

$$
\neg P(a)\vee Q(a,f(a)).
$$

The $\neg P(a)$ branch closes against $P(a)$. On the other branch, instantiate $\forall z\,\neg Q(a,z)$ at $z=f(a)$ to obtain $\neg Q(a,f(a))$, which closes against $Q(a,f(a))$.

![Closed truth tree for the G02 practice inference](images/G02/practice-truth-tree.svg)

Every branch closes, so the argument is valid.
