# Skill Description

Ability to work with Cartesian products, Cartesian powers, and power sets. Describe the structure of their elements, decide whether an object belongs to a constructed set, and calculate the cardinality of finite sets built by nesting these operations.

---

# Sample Problems

Each practice exam problem asks for example elements and a cardinality calculation. Give three **distinct** elements when requested. Show the structure of each element with parentheses and braces, and explain each counting step. Every set listing must contain each element exactly once, including listings inside nested constructions. A factored expression with exponents is an acceptable exact count.

We write $\mathcal P(A)$, $P(A)$, and $2^A$ for the power set of $A$. Throughout, $F_n=\lbrace 0,1,\ldots,n-1\rbrace$.

## Practice Exam Problem 1

Let $B=\lbrace 0,1\rbrace$ and $L=\lbrace p,q,r,s\rbrace$.

1. List three elements of $B^3$.
2. List three elements of $B^2\times\mathcal P(L)$.
3. Let $D=\lbrace d_1,d_2,d_3,d_4,d_5,d_6\rbrace$ be a set of devices and $M=\lbrace \mathrm{idle},\mathrm{ready},\mathrm{busy}\rbrace$ a set of modes. What is the cardinality of $(D\times M)^4\times\mathcal P(D\times M)$? Explain your answer.

## Practice Exam Problem 2

Let $X=F_3=\lbrace 0,1,2\rbrace$ and $Y=\lbrace r,s\rbrace$.

1. List three elements of $\mathcal P(Y)^2$.
2. List three elements of $\mathcal P(X\times Y^2)$.
3. What is the cardinality of $\mathcal P(X\times Y^2)\times\mathcal P(\mathcal P(Y))$? Explain your answer.

Here $X\times Y^2$ can be written using nested pairs $(x,(y_1,y_2))$ or flat triples $(x,y_1,y_2)$, as explained in the tutorial.

## Practice Exam Problem 3

Let $X=\lbrace 0,1,2\rbrace$ and $Y=\lbrace u,v\rbrace$.

1. List three elements of $X^3\times Y^2$.
2. List three elements of $\mathcal P(X)\times\mathcal P(Y^2)$.
3. Calculate $|\mathcal P(X)\times\mathcal P(Y^2)|$, explaining each step.

## Further Practice

1. Let $B=F_2$. Determine whether each object belongs to $B\times\mathcal P(B)$, and explain: $(0,\emptyset)$, $(1,\lbrace 0,1\rbrace)$, $(\lbrace 0\rbrace,1)$, and $(0,\lbrace 2\rbrace)$.
2. Let $B=F_2$. Determine whether each statement is true or false: $\emptyset\in\mathcal P(B)$, $\lbrace \emptyset\rbrace \in\mathcal P(B)$, $\emptyset\in\mathcal P(\mathcal P(B))$, and $\lbrace \emptyset\rbrace \in\mathcal P(\mathcal P(B))$. Explain the difference between the two power sets.
3. Calculate $|\emptyset\times F_3|$, $|\mathcal P(\emptyset)|$, and $|\mathcal P(\mathcal P(\emptyset))|$. List the elements of the last two sets.

# Tutorial

## Read the outermost operation first

The outermost operation tells you what kind of object an element must be.

| Constructed set | Structure of an element |
| --- | --- |
| $A\times B$ | A pair $(a,b)$ with $a\in A$ and $b\in B$ |
| $A^n$ | An ordered $n$-tuple of elements of $A$ |
| $\mathcal P(A)$ | A subset of $A$ |

Then check each component against its own domain. For example, an element of $B^3\times\mathcal P(L)$ is a pair whose first coordinate is a three-bit tuple and whose second coordinate is a subset of $L$.

## Cartesian products and powers

The product $A\times B$ consists of every ordered pair $(a,b)$ with $a\in A$ and $b\in B$. Each choice of $a$ allows $|B|$ choices of $b$, so for finite sets,

$$
|A\times B|=|A|\cdot|B|.
$$

The Cartesian power $A^n$, for a positive integer $n$, consists of all ordered $n$-tuples from $A$. Choices in the positions are independent, so

$$
|A^n|=|A|^n.
$$

Repeated entries are allowed in tuples and sequences. For example, $(1,1,1)\in F_2^3$: order matters, and repeated entries occupy separate positions. A set listing such as $\lbrace 1,1,1\rbrace$ is invalid because an element is repeated.

More generally,

$$
|A_1\times\cdots\times A_n|=\prod_{i=1}^n|A_i|.
$$

The grouping of a product determines the role of each coordinate. In $A\times B^2$, the nested form is $(a,(b_1,b_2))$; in $(A\times B)^2$, it is $((a_1,b_1),(a_2,b_2))$.

These notes accept both nested tuples and their flat forms, following the course's exam convention. The correspondence keeps the entries in order:

$$
(a,(b_1,b_2))\longleftrightarrow(a,b_1,b_2),
$$

$$
((a_1,b_1),(a_2,b_2))\longleftrightarrow(a_1,b_1,a_2,b_2).
$$

Formally, flattening gives a one-to-one correspondence rather than literal equality of ordered objects. For membership and example-element questions here, either representation is accepted when the grouping can be recovered from the stated product. Flatten tuple coordinates only: a subset coordinate must retain its braces, as in $((0,1),\lbrace p,q\rbrace)$ or $(0,1,\lbrace p,q\rbrace)$ for $F_2^2\times\mathcal P(\lbrace p,q\rbrace)$.

If either factor of a binary product is empty, the product is empty: no pair can have a coordinate in the empty factor.

## Power sets

The power set contains all subsets, including the empty set and the whole set:

$$
\mathcal P(\lbrace a,b\rbrace)=\lbrace \emptyset,\lbrace a\rbrace,\lbrace b\rbrace,\lbrace a,b\rbrace \rbrace.
$$

Write each subset exactly once in a power-set listing, and each element exactly once inside a subset. For a subset of a product, the same rule applies to whole tuples: $\lbrace (0,0)\rbrace$ is a valid subset of $F_2^2$, while $\lbrace (0,0),(0,0)\rbrace$ is an invalid set listing. The repeated coordinates inside $(0,0)$ are valid.

If $A$ has $m$ elements, each element has two independent possibilities in a subset: included or excluded. Thus

$$
|\mathcal P(A)|=2^{|A|}.
$$

The notation $2^A$ denotes a **set of subsets**, whereas $2^{|A|}$ denotes its **numerical size**. Similarly, $A^n$ is a set of tuples, while $|A|^n$ is a number.

## Nested operations

A power set and a Cartesian power create different objects. With $A=\lbrace a,b\rbrace$:

| Set | Example element | Cardinality |
| --- | --- | --- |
| $A^2$ | $(a,b)$ | $2^2=4$ |
| $\mathcal P(A)$ | $\lbrace a,b\rbrace$ | $2^2=4$ |
| $\mathcal P(A)^2$ | $(\lbrace a\rbrace,\lbrace a,b\rbrace)$ | $(2^2)^2=16$ |
| $\mathcal P(A^2)$ | $\lbrace (a,a),(b,a)\rbrace$ | $2^{2^2}=16$ |
| $\mathcal P(\mathcal P(A))$ | $\lbrace \emptyset,\lbrace a\rbrace \rbrace$ | $2^{2^2}=16$ |

Equal cardinalities do not make these sets equal. In $\mathcal P(A)^2$, an element is an ordered pair of subsets. In $\mathcal P(A^2)$, it is a set of ordered pairs. In $\mathcal P(\mathcal P(A))$, it is a set whose elements are subsets of $A$.

**Worked example.** Let $A=F_3$ and $B=\lbrace u,v\rbrace$. Describe an element of $T=\mathcal P(A\times B^2)$ and calculate $|T|$.

An element of $A\times B^2$ is a pair such as $(2,(u,v))$. An element of $T$ is a subset containing such pairs, for example,

$$
\lbrace (0,(u,u)),(2,(u,v))\rbrace.
$$

Count from the inside outward:

$$
\begin{aligned}
|B^2|&=2^2=4,\\
|A\times B^2|&=3\cdot4=12,\\
|\mathcal P(A\times B^2)|&=2^{12}=4096.
\end{aligned}
$$

The empty set is also an element of $T$. A proposed nonempty subset belongs to $T$ exactly when every one of its members has the required pair structure and coordinates.

## How to solve a constructed-set problem

For example elements, start from the outermost operation and build objects with the required structure. For membership, check that structure and then check every coordinate or subset member. For cardinality, start with the innermost sets, multiply for products, raise to a power for tuples, use $2^{(\text{size})}$ for power sets.

Keep exponents grouped: $|\mathcal P(\mathcal P(A))|=2^{(2^{|A|})}$, while $|\mathcal P(A)^2|=(2^{|A|})^2$.

# Answers

## Practice Exam Problem 1

1. Three examples are $(0,0,0)$, $(0,1,0)$, and $(1,1,1)$. Each is an ordered triple with entries in $B$.
2. Three examples are $((0,0),\emptyset)$, $((0,1),\lbrace p,r\rbrace)$, and $((1,1),L)$. Each is a pair consisting of a two-bit tuple and a subset of $L$.
3. There are $6\cdot3=18$ device-mode pairs. An element of $(D\times M)^4$ is a sequence of four such pairs, with repetitions allowed. There are $18^4$ sequences and $2^{18}$ subsets of $D\times M$. Choosing one of each independently gives

$$
|(D\times M)^4\times\mathcal P(D\times M)|=18^4\cdot2^{18}.
$$

## Practice Exam Problem 2

1. Three examples are $(\emptyset,\emptyset)$, $(\lbrace r\rbrace,\lbrace s\rbrace)$, and $(Y,\lbrace r\rbrace)$. Each is an ordered pair of subsets of $Y$.
2. Three examples are $\emptyset$, $\lbrace (0,(r,r))\rbrace$, and $\lbrace (1,(r,s)),(2,(s,r))\rbrace$. Each is a subset of $X\times Y^2$.
3. Since $|Y^2|=2^2=4$, we have $|X\times Y^2|=3\cdot4=12$. Hence $|\mathcal P(X\times Y^2)|=2^{12}$. Also $|\mathcal P(Y)|=2^2=4$, so $|\mathcal P(\mathcal P(Y))|=2^4=16$. Therefore

$$
|\mathcal P(X\times Y^2)\times\mathcal P(\mathcal P(Y))|
=2^{12}\cdot2^4=2^{16}=65536.
$$

## Practice Exam Problem 3

1. Three nested examples are $((0,0,0),(u,u))$, $((0,1,2),(u,v))$, and $((2,1,0),(v,v))$. Their flat forms are $(0,0,0,u,u)$, $(0,1,2,u,v)$, and $(2,1,0,v,v)$.
2. Three examples are $(\emptyset,\emptyset)$, $(\lbrace 0\rbrace,\lbrace (u,v)\rbrace)$, and $(X,\lbrace (u,u),(v,v)\rbrace)$. The first coordinate is a subset of $X$; the second is a subset of $Y^2$.
3. There are $2^3=8$ subsets of $X$. There are $2^2=4$ pairs in $Y^2$, hence $2^4=16$ subsets of $Y^2$. Independent choices give $8\cdot16=128$ pairs:

$$
|\mathcal P(X)\times\mathcal P(Y^2)|=2^3\cdot2^{(2^2)}=2^7=128.
$$

## Further Practice

1. The first two objects belong: their first coordinates are in $B$ and their second coordinates are subsets of $B$. The third fails both coordinate requirements. The fourth fails because $\lbrace 2\rbrace \nsubseteq B$.
2. In order: **true, false, true, true**. The empty set is a subset of $B$, but $\lbrace \emptyset\rbrace$ is not, since $\emptyset\notin B$. Both $\emptyset$ and $\lbrace \emptyset\rbrace$ are subsets of $\mathcal P(B)$: the latter contains just $\emptyset$, which is an element of $\mathcal P(B)$.
3. The sizes are 0, 1, and 2. The only subset of $\emptyset$ is $\emptyset$, so

$$
\mathcal P(\emptyset)=\lbrace \emptyset\rbrace,\qquad
\mathcal P(\mathcal P(\emptyset))=\lbrace \emptyset,\lbrace \emptyset\rbrace \rbrace.
$$
