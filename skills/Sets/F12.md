# Skill Description

Ability to read set notation and list the elements of a finite set defined by a set comprehension, including sets of ordered pairs and sets whose elements are subsets of another set. Distinguish membership from inclusion, and use parentheses and braces to show the structure of each element.

---

# Sample Problems

Each practice exam problem asks you to list three finite sets. The problems include numbers, ordered pairs or triples, subsets, and pairs involving subsets. List every element exactly once, with an outer pair of braces around each answer, and explain why your list is complete. A set listing with repeated elements is invalid in this course. Throughout this page, $\mathbb N=\lbrace 0,1,2,\ldots\rbrace$ and $F_n=\lbrace 0,1,\ldots,n-1\rbrace$; $F_0=\emptyset$.

## Practice Exam Problem 1

1. List the elements of $A=\lbrace x\in\mathbb N: 5<x^2<30\rbrace$.
2. List the elements of $B=\lbrace (x,y)\in\mathbb N\times\mathbb N: 1\le x<y\le4\rbrace$.
3. List the elements of $C=\lbrace S\in\mathcal P(\lbrace 2,4,6\rbrace): |S|=2\rbrace$.

Here $\mathcal P(X)$ is the power set of $X$, and $|S|$ is the number of elements in $S$.

## Practice Exam Problem 2

1. List the elements of $D=\lbrace 2x+1: x\in\mathbb N\wedge 1\le x\le4\rbrace$.
2. List the elements of $E=\lbrace (x,y)\in F_3\times F_4: x+y=3\rbrace$.
3. List the elements of $G=\lbrace S\in\mathcal P(\lbrace a,b,c\rbrace): a\in S\wedge |S|\le2\rbrace$.

## Practice Exam Problem 3

1. List the elements of $J=\lbrace x^2: x\in\mathbb N\wedge x+2\le5\rbrace$.
2. List the elements of $T=\lbrace (x,y,z)\in\mathbb N^3: x+y+z=4\wedge x\le y\le z\rbrace$.
3. List the elements of $W=\lbrace S\in\mathcal P(\lbrace 1,2,3,4\rbrace): \sum_{a\in S}a=6\rbrace$.

In part 3, sum the elements of each candidate subset; the empty subset has sum 0.

## Further Practice

1. List the elements of $H=\lbrace (n,S)\in F_3\times\mathcal P(F_2): n+|S|=2\rbrace$.
2. List the elements of $R=\lbrace (S,T)\in\mathcal P(\lbrace a,b\rbrace)\times\mathcal P(\lbrace a,b\rbrace): S\subset T\rbrace$. Here $\subset$ means a proper subset.
3. Let $K=\lbrace \emptyset,\lbrace 0\rbrace \rbrace$. Determine whether each statement is true or false, and explain: $\emptyset\in K$, $\emptyset\subseteq K$, $0\in K$, $\lbrace 0\rbrace \in K$, and $\lbrace 0\rbrace \subseteq K$.

# Tutorial

## Sets, elements, and cardinality

A **set** is a collection of distinct elements. Braces enclose a set, and commas separate its elements. The order of the elements does not matter:

$$
\lbrace 1,2,3\rbrace =\lbrace 3,1,2\rbrace.
$$

Each element must appear exactly once in a set listing. In this course, $\lbrace 1,1,2,3\rbrace$ is **invalid notation** because 1 is repeated. Write $\lbrace 1,2,3\rbrace$ instead.

The statement $x\in A$ means that $x$ is an element of $A$; $x\notin A$ means that it is not. The **cardinality** $|A|$ of a finite set is its number of elements. For example, $|\lbrace 1,2,3\rbrace |=3$.

The empty set $\emptyset=\lbrace \rbrace$ has no elements. The set $\lbrace \emptyset\rbrace$ has one element, which is itself a set. Thus $|\emptyset|=0$ and $|\lbrace \emptyset\rbrace |=1$.

## Commonly used sets

The number systems you have used in algebra are sets. Their usual symbols let us specify which numbers an element or variable may represent.

| Symbol | Set | Description |
| --- | --- | --- |
| $\emptyset$ | Empty set | $\lbrace \rbrace$; no elements |
| $\mathbb N$ | Natural numbers | $\lbrace 0,1,2,\ldots\rbrace$; includes zero in this course |
| $\mathbb Z$ | Integers | $\lbrace \ldots,-2,-1,0,1,2,\ldots\rbrace$ |
| $\mathbb Q$ | Rational numbers | Numbers expressible as $a/b$, where $a,b\in\mathbb Z$ and $b\ne0$ |
| $\mathbb R$ | Real numbers | All numbers on the real number line, including rational and irrational numbers |
| $\mathbb C$ | Complex numbers | Numbers $a+bi$, where $a,b\in\mathbb R$ and $i^2=-1$ |
| $F_n$ | First $n$ natural numbers | $\lbrace 0,1,\ldots,n-1\rbrace$ for $n\ge1$, with $F_0=\emptyset$ |

The older course notes also write $\mathbb F_n$ or $\mathcal F_n$ for $F_n$. For example, $F_3=\lbrace 0,1,2\rbrace$ and $|F_3|=3$.

Read $x\in\mathbb N$ as “$x$ is a natural number” and $x\in\mathbb Z$ as “$x$ is an integer.” Some membership examples are:

* $0\in\mathbb N$ and $0\in\mathbb Z$.
* $-2\in\mathbb Z$, but $-2\notin\mathbb N$.
* $1/2\in\mathbb Q$, but $1/2\notin\mathbb Z$.
* $\sqrt2\in\mathbb R$, but $\sqrt2\notin\mathbb Q$.
* $i\in\mathbb C$, but $i\notin\mathbb R$.

The superscripts $+$ and $-$ select positive and negative elements. For example, $\mathbb Z^+=\lbrace 1,2,3,\ldots\rbrace$, $\mathbb Z^-=\lbrace \ldots,-3,-2,-1\rbrace$, and $\mathbb R^-$ is the set of negative real numbers. Zero belongs to neither the positive nor the negative part.

The domain affects the answer to a comprehension. With the same condition $x^2\le4$, we get

$$
\lbrace x\in\mathbb N:x^2\le4\rbrace =\lbrace 0,1,2\rbrace,
$$

$$
\lbrace x\in\mathbb Z:x^2\le4\rbrace =\lbrace -2,-1,0,1,2\rbrace.
$$

The integer domain also permits negative values of $x$.

## Membership and subsets

$A\subseteq B$ means that every element of $A$ is also an element of $B$:

$$
(A\subseteq B)\leftrightarrow(\forall x . (x\in A)\rightarrow(x\in B)).
$$

The notation $A\subset B$ means a proper subset in these notes: $A\subseteq B$ and $A\ne B$. A set is a subset of itself, and $\emptyset$ is a subset of every set.

Membership asks whether an object appears as an element; inclusion asks whether all the elements of one set belong to another. For example, if $A=\lbrace 0,1\rbrace$, then $0\in A$ and $\lbrace 0\rbrace \subseteq A$, but $\lbrace 0\rbrace \notin A$. If $T=\lbrace \lbrace 0\rbrace,\lbrace 1\rbrace \rbrace$, then $\lbrace 0\rbrace \in T$, while $0\notin T$.

Two sets are equal exactly when they have the same elements:

$$
(A=B)\leftrightarrow(\forall x . (x\in A)\leftrightarrow(x\in B)).
$$

## Set comprehensions

A comprehension specifies the objects to consider and a condition for keeping them:

$$
\lbrace x\in S: P(x)\rbrace.
$$

Read this as “the set of all $x$ in $S$ such that $P(x)$.” A vertical bar can replace the colon: $\lbrace x\in S\mid P(x)\rbrace$.

The expression before the colon can also transform the selected objects. For example,

$$
\lbrace x^2: x\in\mathbb Z\wedge -2\le x\le2\rbrace =\lbrace 0,1,4\rbrace.
$$

The allowed inputs are $-2,-1,0,1,2$, but the elements of the resulting set are their squares. Different inputs can produce the same output; write that output exactly once in the resulting set listing. The comprehension is valid, while a listing such as $\lbrace 4,1,0,1,4\rbrace$ is invalid.

Quantifiers inside comprehensions use the same dot notation as in predicate calculus. For example,

$$
\lbrace x\in\mathbb Z: \exists k\in\mathbb Z . x=2k+1\rbrace
$$

is the set of odd integers. The dot begins the quantifier's scope.

## Products and ordered pairs

The Cartesian product $A\times B$ contains the ordered pairs $(a,b)$ with $a\in A$ and $b\in B$. For example,

$$
\lbrace 1,2\rbrace \times\lbrace a,b\rbrace =\lbrace (1,a),(1,b),(2,a),(2,b)\rbrace.
$$

Parentheses describe an ordered pair; braces describe a set. For distinct $a$ and $b$, $(a,b)\ne(b,a)$, while $\lbrace a,b\rbrace =\lbrace b,a\rbrace$. Repeated coordinates are allowed in tuples: $(1,1)$ is a valid pair. The set listing $\lbrace 1,1\rbrace$ is invalid.

To enumerate $\lbrace (x,y)\in F_3\times F_3: x<y\rbrace$, try each first coordinate and keep the allowed second coordinates:

| $x$ | Allowed $y$ | Pairs retained |
| --- | --- | --- |
| 0 | 1, 2 | $(0,1),(0,2)$ |
| 1 | 2 | $(1,2)$ |
| 2 | none | none |

The answer is $\lbrace (0,1),(0,2),(1,2)\rbrace$. This checks every possible first coordinate, so no pair is missing.

## Power sets and nested braces

The **power set** $\mathcal P(A)$, also written $P(A)$ or $2^A$, is the set of all subsets of $A$:

$$
S\in\mathcal P(A)\leftrightarrow S\subseteq A.
$$

For example,

$$
\mathcal P(\lbrace p,q\rbrace)=\lbrace \emptyset,\lbrace p\rbrace,\lbrace q\rbrace,\lbrace p,q\rbrace \rbrace.
$$

Include the empty subset and the whole set. Each element is a set, so keep its braces inside the outer braces. A useful enumeration strategy is to list subsets by size: size 0, then size 1, then size 2, and so on.

For $\lbrace S\in\mathcal P(\lbrace p,q,r\rbrace): p\notin S\rbrace$, retain only the subsets without $p$:

$$
\lbrace \emptyset,\lbrace q\rbrace,\lbrace r\rbrace,\lbrace q,r\rbrace \rbrace.
$$

For a condition involving $|S|$ or a sum of elements, calculate that value for each candidate subset. For pairs $(S,T)$ with $S\subseteq T$, fix $S$ and list all its allowed supersets $T$; a proper-subset condition also excludes $S=T$.

If a product has a power set as a factor, its elements mix pairs and sets. For example, $(0,\lbrace 1\rbrace)\in F_2\times\mathcal P(F_2)$. The outer parentheses enclose the pair; the inner braces enclose its second coordinate.

## A reliable enumeration method

1. Identify the domain and the kind of element required: a number, a tuple, or a set.
2. Use the bounds to make a finite list of candidates. For a power set, list subsets by size.
3. Test the condition on each candidate, retaining the output specified before the colon.
4. Remove duplicate outputs and enclose the complete list in braces.
5. Explain why your candidate list covers all possibilities.

Checking $|\mathcal P(A)|=2^{|A|}$ can catch missing subsets; [F14](F14.md) explains this count. A count alone does not replace the requested list.

# Answers

## Practice Exam Problem 1

1. $A=\lbrace 3,4,5\rbrace$. The squares are $9,16,25$. For $x\le2$, $x^2\le4$; for $x\ge6$, $x^2\ge36$. These exclude every other natural number.
2. $B=\lbrace (1,2),(1,3),(1,4),(2,3),(2,4),(3,4)\rbrace$. For $x=1$, use $y=2,3,4$; for $x=2$, use $y=3,4$; for $x=3$, use $y=4$. No other $x$ permits $x<y\le4$.
3. $C=\lbrace \lbrace 2,4\rbrace,\lbrace 2,6\rbrace,\lbrace 4,6\rbrace \rbrace$. These are all the two-element subsets. The answer is a set of three sets, so it needs both outer and inner braces.

## Practice Exam Problem 2

1. $D=\lbrace 3,5,7,9\rbrace$. The allowed inputs $1,2,3,4$ produce these four values of $2x+1$.
2. $E=\lbrace (0,3),(1,2),(2,1)\rbrace$. The first coordinate is 0, 1, or 2; the equation forces $y=3-x$, which belongs to $F_4$ in every case. The pair $(3,0)$ is excluded because $3\notin F_3$.
3. $G=\lbrace \lbrace a\rbrace,\lbrace a,b\rbrace,\lbrace a,c\rbrace \rbrace$. The empty set fails $a\in S$; the other singleton and two-element subsets also fail it. The whole set contains $a$ but has size 3.

## Practice Exam Problem 3

1. The allowed inputs are $0,1,2,3$, giving $J=\lbrace 0,1,4,9\rbrace$.
2. Since $x\le y\le z$ and the sum is 4, $3x\le4$, so $x$ is 0 or 1. For $x=0$, the allowed $(y,z)$ are $(0,4),(1,3),(2,2)$. For $x=1$, only $(y,z)=(1,2)$ works. Thus

$$
T=\lbrace (0,0,4),(0,1,3),(0,2,2),(1,1,2)\rbrace.
$$

3. No singleton has sum 6. The only two-element subset with sum 6 is $\lbrace 2,4\rbrace$, and the only three-element subset is $\lbrace 1,2,3\rbrace$. The empty subset has sum 0 and the whole set has sum 10. Hence $W=\lbrace \lbrace 2,4\rbrace,\lbrace 1,2,3\rbrace \rbrace$.

## Further Practice

1. The four subsets of $F_2$ have sizes 0, 1, 1, and 2, respectively. The equation gives $n=2-|S|$, so each determines exactly one allowed first coordinate, giving

$$
H=\lbrace (2,\emptyset),(1,\lbrace 0\rbrace),(1,\lbrace 1\rbrace),(0,\lbrace 0,1\rbrace)\rbrace.
$$

2. For $S=\emptyset$, the proper supersets are $\lbrace a\rbrace$, $\lbrace b\rbrace$, and $\lbrace a,b\rbrace$. Each singleton has only the whole set as a proper superset, and the whole set has none. Thus

$$
R=\lbrace (\emptyset,\lbrace a\rbrace),(\emptyset,\lbrace b\rbrace),(\emptyset,\lbrace a,b\rbrace),(\lbrace a\rbrace,\lbrace a,b\rbrace),(\lbrace b\rbrace,\lbrace a,b\rbrace)\rbrace.
$$

3. In the order asked: **true, true, false, true, false**. The elements of $K$ are $\emptyset$ and $\lbrace 0\rbrace$, and $0$ is neither of them. The empty set is always a subset. The claim $\lbrace 0\rbrace \subseteq K$ would require $0\in K$, which is false.
