# Skill Description

Ability to read set notation and list the elements of a finite set defined by a set comprehension, including sets of ordered pairs and sets whose elements are subsets of another set. Distinguish membership from inclusion, and use parentheses and braces to show the structure of each element.

---

# Sample Problems

Each practice exam problem asks you to list three finite sets. The problems include numbers, ordered pairs or triples, subsets, and pairs involving subsets. List every element explicitly, with an outer pair of braces around each answer, and explain why your list is complete. Throughout this page, $\mathbb N=\{0,1,2,\ldots\}$ and $F_n=\{0,1,\ldots,n-1\}$; $F_0=\emptyset$.

## Practice Exam Problem 1

1. List the elements of $A=\{x\in\mathbb N: 5<x^2<30\}$.
2. List the elements of $B=\{(x,y)\in\mathbb N\times\mathbb N: 1\le x<y\le4\}$.
3. List the elements of $C=\{S\in\mathcal P(\{2,4,6\}): |S|=2\}$.

Here $\mathcal P(X)$ is the power set of $X$, and $|S|$ is the number of elements in $S$.

## Practice Exam Problem 2

1. List the elements of $D=\{2x+1: x\in\mathbb N\wedge 1\le x\le4\}$.
2. List the elements of $E=\{(x,y)\in F_3\times F_4: x+y=3\}$.
3. List the elements of $G=\{S\in\mathcal P(\{a,b,c\}): a\in S\wedge |S|\le2\}$.

## Practice Exam Problem 3

1. List the elements of $J=\{x^2: x\in\mathbb N\wedge x+2\le5\}$.
2. List the elements of $T=\{(x,y,z)\in\mathbb N^3: x+y+z=4\wedge x\le y\le z\}$.
3. List the elements of $W=\{S\in\mathcal P(\{1,2,3,4\}): \sum_{a\in S}a=6\}$.

In part 3, sum the elements of each candidate subset; the empty subset has sum 0.

## Further Practice

1. List the elements of $H=\{(n,S)\in F_3\times\mathcal P(F_2): n+|S|=2\}$.
2. List the elements of $R=\{(S,T)\in\mathcal P(\{a,b\})\times\mathcal P(\{a,b\}): S\subset T\}$. Here $\subset$ means a proper subset.
3. Let $K=\{\emptyset,\{0\}\}$. Determine whether each statement is true or false, and explain: $\emptyset\in K$, $\emptyset\subseteq K$, $0\in K$, $\{0\}\in K$, and $\{0\}\subseteq K$.

# Tutorial

## Sets, elements, and cardinality

A **set** is a collection of distinct elements. Braces enclose a set, and commas separate its elements. Order and repetition do not change a set:

$$
\{1,2,3\}=\{3,1,2\}=\{1,1,2,3\}.
$$

The statement $x\in A$ means that $x$ is an element of $A$; $x\notin A$ means that it is not. The **cardinality** $|A|$ of a finite set is its number of distinct elements. For example, $|\{1,1,2\}|=2$.

The empty set $\emptyset=\{\}$ has no elements. The set $\{\emptyset\}$ has one element, which is itself a set. Thus $|\emptyset|=0$ and $|\{\emptyset\}|=1$.

## Membership and subsets

$A\subseteq B$ means that every element of $A$ is also an element of $B$:

$$
(A\subseteq B)\leftrightarrow(\forall x . (x\in A)\rightarrow(x\in B)).
$$

The notation $A\subset B$ means a proper subset in these notes: $A\subseteq B$ and $A\ne B$. A set is a subset of itself, and $\emptyset$ is a subset of every set.

Membership asks whether an object appears as an element; inclusion asks whether all the elements of one set belong to another. For example, if $A=\{0,1\}$, then $0\in A$ and $\{0\}\subseteq A$, but $\{0\}\notin A$. If $T=\{\{0\},\{1\}\}$, then $\{0\}\in T$, while $0\notin T$.

Two sets are equal exactly when they have the same elements:

$$
(A=B)\leftrightarrow(\forall x . (x\in A)\leftrightarrow(x\in B)).
$$

## Set comprehensions

A comprehension specifies the objects to consider and a condition for keeping them:

$$
\{x\in S: P(x)\}.
$$

Read this as “the set of all $x$ in $S$ such that $P(x)$.” A vertical bar can replace the colon: $\{x\in S\mid P(x)\}$.

The expression before the colon can also transform the selected objects. For example,

$$
\{x^2: x\in\mathbb Z\wedge -2\le x\le2\}=\{0,1,4\}.
$$

The allowed inputs are $-2,-1,0,1,2$, but the elements of the resulting set are their squares. List a repeated output only once.

Quantifiers inside comprehensions use the same dot notation as in predicate calculus. For example,

$$
\{x\in\mathbb Z: \exists k\in\mathbb Z . x=2k+1\}
$$

is the set of odd integers. The dot begins the quantifier's scope.

## Products and ordered pairs

The Cartesian product $A\times B$ contains the ordered pairs $(a,b)$ with $a\in A$ and $b\in B$. For example,

$$
\{1,2\}\times\{a,b\}=\{(1,a),(1,b),(2,a),(2,b)\}.
$$

Parentheses describe an ordered pair; braces describe a set. In general, $(a,b)\ne(b,a)$ when $a\ne b$, while $\{a,b\}=\{b,a\}$.

To enumerate $\{(x,y)\in F_3\times F_3: x<y\}$, try each first coordinate and keep the allowed second coordinates:

| $x$ | Allowed $y$ | Pairs retained |
| --- | --- | --- |
| 0 | 1, 2 | $(0,1),(0,2)$ |
| 1 | 2 | $(1,2)$ |
| 2 | none | none |

The answer is $\{(0,1),(0,2),(1,2)\}$. This checks every possible first coordinate, so no pair is missing.

## Power sets and nested braces

The **power set** $\mathcal P(A)$, also written $P(A)$ or $2^A$, is the set of all subsets of $A$:

$$
S\in\mathcal P(A)\leftrightarrow S\subseteq A.
$$

For example,

$$
\mathcal P(\{p,q\})=\{\emptyset,\{p\},\{q\},\{p,q\}\}.
$$

Include the empty subset and the whole set. Each element is a set, so keep its braces inside the outer braces. A useful enumeration strategy is to list subsets by size: size 0, then size 1, then size 2, and so on.

For $\{S\in\mathcal P(\{p,q,r\}): p\notin S\}$, retain only the subsets without $p$:

$$
\{\emptyset,\{q\},\{r\},\{q,r\}\}.
$$

For a condition involving $|S|$ or a sum of elements, calculate that value for each candidate subset. For pairs $(S,T)$ with $S\subseteq T$, fix $S$ and list all its allowed supersets $T$; a proper-subset condition also excludes $S=T$.

If a product has a power set as a factor, its elements mix pairs and sets. For example, $(0,\{1\})\in F_2\times\mathcal P(F_2)$. The outer parentheses enclose the pair; the inner braces enclose its second coordinate.

## A reliable enumeration method

1. Identify the domain and the kind of element required: a number, a tuple, or a set.
2. Use the bounds to make a finite list of candidates. For a power set, list subsets by size.
3. Test the condition on each candidate, retaining the output specified before the colon.
4. Remove duplicate outputs and enclose the complete list in braces.
5. Explain why your candidate list covers all possibilities.

Checking $|\mathcal P(A)|=2^{|A|}$ can catch missing subsets; [F14](F14.md) explains this count. A count alone does not replace the requested list.

# Answers

## Practice Exam Problem 1

1. $A=\{3,4,5\}$. The squares are $9,16,25$. For $x\le2$, $x^2\le4$; for $x\ge6$, $x^2\ge36$. These exclude every other natural number.
2. $B=\{(1,2),(1,3),(1,4),(2,3),(2,4),(3,4)\}$. For $x=1$, use $y=2,3,4$; for $x=2$, use $y=3,4$; for $x=3$, use $y=4$. No other $x$ permits $x<y\le4$.
3. $C=\{\{2,4\},\{2,6\},\{4,6\}\}$. These are all the two-element subsets. The answer is a set of three sets, so it needs both outer and inner braces.

## Practice Exam Problem 2

1. $D=\{3,5,7,9\}$. The allowed inputs $1,2,3,4$ produce these four values of $2x+1$.
2. $E=\{(0,3),(1,2),(2,1)\}$. The first coordinate is 0, 1, or 2; the equation forces $y=3-x$, which belongs to $F_4$ in every case. The pair $(3,0)$ is excluded because $3\notin F_3$.
3. $G=\{\{a\},\{a,b\},\{a,c\}\}$. The empty set fails $a\in S$; the other singleton and two-element subsets also fail it. The whole set contains $a$ but has size 3.

## Practice Exam Problem 3

1. The allowed inputs are $0,1,2,3$, giving $J=\{0,1,4,9\}$.
2. Since $x\le y\le z$ and the sum is 4, $3x\le4$, so $x$ is 0 or 1. For $x=0$, the allowed $(y,z)$ are $(0,4),(1,3),(2,2)$. For $x=1$, only $(y,z)=(1,2)$ works. Thus

$$
T=\{(0,0,4),(0,1,3),(0,2,2),(1,1,2)\}.
$$

3. No singleton has sum 6. The only two-element subset with sum 6 is $\{2,4\}$, and the only three-element subset is $\{1,2,3\}$. The empty subset has sum 0 and the whole set has sum 10. Hence $W=\{\{2,4\},\{1,2,3\}\}$.

## Further Practice

1. The four subsets of $F_2$ have sizes 0, 1, 1, and 2, respectively. The equation gives $n=2-|S|$, so each determines exactly one allowed first coordinate, giving

$$
H=\{(2,\emptyset),(1,\{0\}),(1,\{1\}),(0,\{0,1\})\}.
$$

2. For $S=\emptyset$, the proper supersets are $\{a\}$, $\{b\}$, and $\{a,b\}$. Each singleton has only the whole set as a proper superset, and the whole set has none. Thus

$$
R=\{(\emptyset,\{a\}),(\emptyset,\{b\}),(\emptyset,\{a,b\}),(\{a\},\{a,b\}),(\{b\},\{a,b\})\}.
$$

3. In the order asked: **true, true, false, true, false**. The elements of $K$ are $\emptyset$ and $\{0\}$, and $0$ is neither of them. The empty set is always a subset. The claim $\{0\}\subseteq K$ would require $0\in K$, which is false.
