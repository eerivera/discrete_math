# Skill Description

Ability to calculate with union, intersection, difference, and complement; simplify set expressions using Boolean algebra laws; and prove identities or inferences about sets. When a proposed identity or inference is false, give a counterexample that shows exactly what fails.

---

# Sample Problems

Each practice exam problem combines calculations on explicitly given sets with a claim about arbitrary sets. Show intermediate calculations. For a general claim, give a convincing proof or a counterexample; checking one example cannot prove an identity.

All complements are relative to the stated universe $U$.

## Practice Exam Problem 1

Let $U=\{0,1,2,3,4,5,6,7\}$, $A=\{0,2,4,6\}$, $B=\{1,2,5,6\}$, and $C=\{0,1,2,3\}$.

1. List the elements of $(A\cap B)\cup C$.
2. List the elements of $(A\cup C)\cap(B\cup C)$.
3. List the elements of $B-(C-A)$.
4. Is $(X\cup Y)^c=X^c\cap Y^c$ true for every pair of subsets $X,Y$ of a common universe? Prove it or give a counterexample.

## Practice Exam Problem 2

Let $U=\{a,b,c,d,e,f,g\}$, $A=\{a,c,e\}$, $B=\{b,c,f\}$, and $C=\{a,b,c,d\}$.

1. List the elements of $(A\cup B)^c\cap C$.
2. List the elements of $(A-C)\cup(B\cap C)$.
3. List the elements of $C-(A-B)$.
4. Is $X-(Y\cap Z)=(X-Y)\cap(X-Z)$ true for all subsets $X,Y,Z$ of a common universe? Prove it or give a counterexample.

## Further Practice

1. Simplify $(X\cap Y)\cup(X\cap Y^c)$ using named laws.
2. Simplify $(X\cup Y)\cap(X\cup Y^c)$ using named laws.
3. Prove the inference: if $X\subseteq Y$ and $Y\cap Z=\emptyset$, then $X\cap Z=\emptyset$.
4. Is the converse inference valid: if $X\cap Z=\emptyset$ and $X\subseteq Y$, then $Y\cap Z=\emptyset$? Prove it or give a counterexample.

# Tutorial

## Operations and their membership conditions

Fix a universe $U$ containing every set under discussion. Complements refer to this same $U$, and $x$ ranges over $U$.

| Set expression | Condition on $x$ |
| --- | --- |
| $A\cup B$ (union) | $(x\in A)\vee(x\in B)$ |
| $A\cap B$ (intersection) | $(x\in A)\wedge(x\in B)$ |
| $A-B$ (difference) | $(x\in A)\wedge\neg(x\in B)$ |
| $A^c=\overline A=U-A$ (complement) | $\neg(x\in A)$ |

Union uses inclusive “or.” Difference is directional: $A-B$ retains elements of $A$ that are absent from $B$. In general, $A-B\ne B-A$.

For instance, with $U=\{0,1,2,3,4\}$, $A=\{0,1,2\}$, and $B=\{2,3\}$,

$$
A\cup B=\{0,1,2,3\},\qquad A\cap B=\{2\},
$$

$$
A-B=\{0,1\},\qquad B-A=\{3\},\qquad A^c=\{3,4\}.
$$

The shared element 2 appears exactly once in the union listing. Write every element of a result exactly once; repeating an element makes the set listing invalid.

Calculate a compound expression from the inside outward. For $A-(B-A)$, first find $B-A$, then remove those elements from $A$. Do not treat difference as associative: $(A-B)-C$ and $A-(B-C)$ can be different.

## Why Boolean algebra applies

For an arbitrary $x\in U$, treat “$x\in A$” as a proposition $P$, “$x\in B$” as $Q$, and so on. Union corresponds to $\vee$, intersection to $\wedge$, and complement to $\neg$. The sets $\emptyset$ and $U$ correspond to false and true membership conditions.

Sets are equal when their membership conditions are equivalent for every $x\in U$. This lets us turn logical equivalences into set identities. For example, the propositional law $\neg(P\vee Q)\equiv(\neg P\wedge\neg Q)$ gives $(A\cup B)^c=A^c\cap B^c$.

## Laws of set algebra

In these identities, all sets are subsets of the same universe $U$.

| Law | Union form | Intersection form |
| --- | --- | --- |
| Commutative | $A\cup B=B\cup A$ | $A\cap B=B\cap A$ |
| Associative | $(A\cup B)\cup C=A\cup(B\cup C)$ | $(A\cap B)\cap C=A\cap(B\cap C)$ |
| Idempotent | $A\cup A=A$ | $A\cap A=A$ |
| Identity | $A\cup\emptyset=A$ | $A\cap U=A$ |
| Domination | $A\cup U=U$ | $A\cap\emptyset=\emptyset$ |
| Complement | $A\cup A^c=U$ | $A\cap A^c=\emptyset$ |
| Absorption | $A\cup(A\cap B)=A$ | $A\cap(A\cup B)=A$ |
| Distributive | $A\cup(B\cap C)=(A\cup B)\cap(A\cup C)$ | $A\cap(B\cup C)=(A\cap B)\cup(A\cap C)$ |
| De Morgan | $(A\cup B)^c=A^c\cap B^c$ | $(A\cap B)^c=A^c\cup B^c$ |

Also, $(A^c)^c=A$, $\emptyset^c=U$, $U^c=\emptyset$, and $A-B=A\cap B^c$.

Mixed union and intersection expressions need parentheses to make their grouping clear. Complement applies to the entire expression under the bar or before the superscript. For example, $(A\cap B)^c$ complements an intersection, while $A\cap B^c$ complements only $B$.

## Worked algebraic simplification

Simplify $A-(B-C)$.

$$
\begin{aligned}
A-(B-C)
&=A\cap(B-C)^c &&\text{difference}\\
&=A\cap(B\cap C^c)^c &&\text{difference}\\
&=A\cap(B^c\cup(C^c)^c) &&\text{De Morgan}\\
&=A\cap(B^c\cup C) &&\text{double complement}\\
&=(A\cap B^c)\cup(A\cap C) &&\text{distributive}\\
&=(A-B)\cup(A\cap C) &&\text{difference}.
\end{aligned}
$$

A chain of identities proves equality for arbitrary sets. State the law that justifies each step. In particular, $A-(B-C)$ is not generally $(A-B)-C$.

## Worked proof using membership

**Claim.** $(A\cap B)^c=A^c\cup B^c$.

Fix an arbitrary $x\in U$. Then

$$
\begin{aligned}
x\in(A\cap B)^c
&\leftrightarrow\neg(x\in A\cap B) &&\text{complement}\\
&\leftrightarrow\neg((x\in A)\wedge(x\in B)) &&\text{intersection}\\
&\leftrightarrow(\neg(x\in A)\vee\neg(x\in B)) &&\text{De Morgan in logic}\\
&\leftrightarrow((x\in A^c)\vee(x\in B^c)) &&\text{complement}\\
&\leftrightarrow x\in A^c\cup B^c &&\text{union}.
\end{aligned}
$$

The two sides have exactly the same elements, so they are equal. **Q.E.D.**

Every link is an iff, which proves both directions of membership. A Venn diagram can also support a proof when you explain why both expressions select exactly the same regions. Drawing one particular pair of sets does not establish the universal identity.

## Subset inferences and counterexamples

To prove $A\subseteq B$, fix an arbitrary $x\in A$ and show $x\in B$. For example, $A\cap B\subseteq A$ follows directly from the definition of intersection.

To disprove an inference, make **every premise true and the conclusion false**. To disprove a set identity, find an element belonging to exactly one side. A small universe often suffices.

For example, the inference “$A\cap B=\emptyset$, therefore $A=\emptyset$” fails with $U=\{0\}$, $A=\{0\}$, and $B=\emptyset$. The intersection is empty, but $A$ is not.

# Answers

## Practice Exam Problem 1

1. $A\cap B=\{2,6\}$, so $(A\cap B)\cup C=\{0,1,2,3,6\}$.
2. $A\cup C=\{0,1,2,3,4,6\}$ and $B\cup C=\{0,1,2,3,5,6\}$. Their intersection is $\{0,1,2,3,6\}$. The equality with part 1 is an instance of the distributive law.
3. $C-A=\{1,3\}$, so $B-(C-A)=\{2,5,6\}$.
4. **True.** Fix any $x$ in the common universe. By the definitions and De Morgan's law in logic,

$$
\begin{aligned}
x\in(X\cup Y)^c
&\leftrightarrow\neg((x\in X)\vee(x\in Y))\\
&\leftrightarrow(\neg(x\in X)\wedge\neg(x\in Y))\\
&\leftrightarrow x\in X^c\cap Y^c.
\end{aligned}
$$

Both sides have the same elements. **Q.E.D.**

## Practice Exam Problem 2

1. $A\cup B=\{a,b,c,e,f\}$, so $(A\cup B)^c=\{d,g\}$. Intersecting with $C$ gives $\{d\}$.
2. $A-C=\{e\}$ and $B\cap C=\{b,c\}$, giving $\{b,c,e\}$.
3. $A-B=\{a,e\}$, so $C-(A-B)=\{b,c,d\}$.
4. **False.** Let $U=\{0\}$, $X=Y=\{0\}$, and $Z=\emptyset$. Then $Y\cap Z=\emptyset$, so the left side is $X-\emptyset=\{0\}$. The right side is $\emptyset\cap\{0\}=\emptyset$. The element $0$ belongs only to the left side. The valid identity uses union: $X-(Y\cap Z)=(X-Y)\cup(X-Z)$.

## Further Practice

1. By distribution, complement, and identity,

$$
(X\cap Y)\cup(X\cap Y^c)=X\cap(Y\cup Y^c)=X\cap U=X.
$$

2. By distribution, complement, and identity,

$$
(X\cup Y)\cap(X\cup Y^c)=X\cup(Y\cap Y^c)=X\cup\emptyset=X.
$$

3. Assume $X\subseteq Y$ and $Y\cap Z=\emptyset$. If an element $x$ were in $X\cap Z$, then $x\in X$ and $x\in Z$. Inclusion gives $x\in Y$, hence $x\in Y\cap Z$, contradicting its emptiness. Thus $X\cap Z=\emptyset$. **Q.E.D.**
4. **Invalid.** Use $U=\{0,1\}$, $X=\{0\}$, $Y=\{0,1\}$, and $Z=\{1\}$. Both premises hold, but $Y\cap Z=\{1\}\ne\emptyset$.
