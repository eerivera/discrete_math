# Skill Description

Ability to write a well-structured proof of a theorem, proposition, lemma, or corollary using proof by cases. State cases that cover every possibility, prove the same conclusion in each case, and explain why this establishes the original claim.

---

# Sample Problems

Write a complete proof by cases for each problem. Explain why your cases cover every integer.

## Problem 1

Prove that $n^2+n$ is even for every integer $n$.

## Problem 2

Prove that $n^3-n$ is divisible by 3 for every integer $n$. You may use the division algorithm: every integer has exactly one of the forms $3k$, $3k+1$, or $3k+2$, for an integer $k$.

# Tutorial

## Why cases work

Suppose that at least one of $A_1,\ldots,A_r$ must hold and that each case implies $C$. Then $C$ follows. In propositional logic, the following is a tautology:

$$
\bigl((A_1\vee\cdots\vee A_r)\wedge(A_1\rightarrow C)\wedge\cdots\wedge(A_r\rightarrow C)\bigr)\rightarrow C.
$$

Cases must be exhaustive, but they do not have to be mutually exclusive. Choose cases that make the definitions or calculations easier. For integers, even/odd cases often help with parity, and remainder cases often help with divisibility. For real numbers, positive/negative cases omit zero unless the hypothesis excludes it.

## A proof template

1. Fix an arbitrary object in the stated domain and retain the hypotheses.
2. List the cases and explain why at least one must occur.
3. In each case, use its extra assumption to prove the required conclusion.
4. Conclude that the claim holds in every case, hence for the arbitrary object.

Showing one example in each case is insufficient: the argument must cover every object satisfying that case.

## Worked geometric example

**Theorem.** If every point of a $1\times1$ square panel, including its boundary, is colored either black or white, then two points of the same color are exactly 1 unit apart.

**Proof.** Choose adjacent corners $A$ and $B$, whose distance is 1. If they have the same color, they are the desired pair.

Otherwise they have different colors. Take the point $P$ inside the square that forms an equilateral triangle with $A$ and $B$. For example, if $A=(0,0)$ and $B=(1,0)$, use $P=(1/2,\sqrt{3}/2)$. Both $AP$ and $BP$ have length 1. If $P$ is black, pair it with the black corner; if $P$ is white, pair it with the white corner. These are all possible colors of $P$.

Thus in every case there are two points of the same color exactly 1 unit apart. **Q.E.D.**

This is a case split containing a second, smaller case split. The [unit overview](README.md#proofs-by-cases) also presents this example and the parity example below.

# Answers

## Problem 1

**Proof.** Let $n$ be an arbitrary integer. Every integer is even or odd.

* If $n=2k$ for an integer $k$, then $n^2+n=4k^2+2k=2(2k^2+k)$, which is even.
* If $n=2k+1$ for an integer $k$, then $n^2+n=4k^2+6k+2=2(2k^2+3k+1)$, which is even.

The parenthesized quantities are integers, so both cases establish that $n^2+n$ is even. **Q.E.D.**

Alternatively, $n^2+n=n(n+1)$, and one of two consecutive integers is even. This shorter argument uses the same parity distinction implicitly.

## Problem 2

**Proof.** Let $n$ be an arbitrary integer. By the division algorithm there is an integer $k$ such that one of the following three cases holds.

* If $n=3k$, then $n^3-n=27k^3-3k=3(9k^3-k)$.
* If $n=3k+1$, then $n^3-n=27k^3+27k^2+6k=3(9k^3+9k^2+2k)$.
* If $n=3k+2$, then $n^3-n=27k^3+54k^2+33k+6=3(9k^3+18k^2+11k+2)$.

In each case, $n^3-n$ is 3 times an integer. The cases cover all integers, so 3 divides $n^3-n$ for every integer $n$. **Q.E.D.**
