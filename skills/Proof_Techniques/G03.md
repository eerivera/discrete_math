# Skill Description

Ability to write a well-structured proof of a theorem, proposition, lemma, or corollary using a combination of the following basic techniques:

* direct proof;
* proof of the contrapositive;
* proof by contradiction, possibly using the well-ordering principle;
* proof by cases; and
* proof by induction.

Choose methods that fit the statement, identify where each method is used, and explain how the parts establish the complete claim. A proof need not use every technique.

---

# Sample Problems

## Problem 1

Prove that every integer $n\ge2$ is a product of primes. A product may consist of a single prime. Use contradiction and the well-ordering principle, with cases as needed. You may use the definition that an integer $n\ge2$ is either prime or composite; in the composite case, $n=ab$ for integers $2\le a,b<n$.

This problem asks for existence of a prime factorization, not uniqueness.

## Problem 2

Let $s_0=0$, $s_1=1$, and $s_n=4(s_{n-1}-s_{n-2})$ for $n\ge2$. Prove that $s_n=n2^{n-1}$ for every integer $n\ge0$, and deduce that $s_n$ is odd if and only if $n=1$.

Use induction for the formula, then cases or the two directions of the biconditional for the parity claim.

# Tutorial

This skill tests whether you understand the other proof skills and can combine them to prove more complex theorems. Review [F08](F08.md), [F09](F09.md), [F10](F10.md), and [F11](F11.md) for the individual methods.

## Plan the proof from the statement

| Form of the claim | A useful starting point |
| --- | --- |
| If $A$, then $B$ | Assume $A$ and derive $B$, or prove the contrapositive. |
| $A$ if and only if $B$ | Prove both directions; the methods may differ. |
| A claim for every integer $n\ge n_0$ | Try induction with the correct base case or a least-counterexample argument. |
| Objects have different possible forms | Split into exhaustive cases within the main proof. |
| An object with certain properties cannot exist | Assume it exists and derive a contradiction. |

An outer method does not restrict every inner step. A contradiction proof can split into cases; an induction step can use a direct proof or a contradiction. Keep track of which assumptions apply in each part.

## Well-ordering and the least counterexample

The **well-ordering principle** says that every nonempty set of nonnegative integers has a least element. The corresponding statement for positive integers is equivalent.

To use it, assume that a universal claim is false and form the set of integer counterexamples. Choose its least element $n$. Rule out the starting values first. Then use the fact that every smaller value in the theorem’s domain satisfies the claim. Derive a contradiction, often by constructing a smaller counterexample or proving that $n$ itself satisfies the claim.

The restriction to nonnegative integers matters: a nonempty set of arbitrary integers or positive real numbers need not have a least element. Do not assume the counterexample set is nonempty without first assuming the theorem is false.

## Worked combination: a biconditional

**Theorem.** For every integer $n$, $n^2$ is even if and only if $n$ is even.

**Proof.** For one direction, use a direct proof. If $n=2k$ for an integer $k$, then $n^2=2(2k^2)$ is even.

For the other direction, use the contrapositive. If $n$ is not even, then $n=2k+1$ for an integer $k$. Thus $n^2=2(2k^2+2k)+1$ is odd, so it is not even. This proves that if $n^2$ is even, then $n$ is even.

Both directions hold, establishing the biconditional. **Q.E.D.**

## Check the whole argument

Make sure every case reaches the required conclusion, every use of induction involves smaller indices in the domain, and every contradiction identifies incompatible statements. Do not use the theorem being proved as an unexplained lemma.

# Answers

## Problem 1

**Proof (contradiction, well-ordering, and cases).** Suppose some integer at least 2 is not a product of primes. By well-ordering, choose the smallest such integer $n$.

If $n$ is prime, it is already a product of one prime, contradicting its choice.

If $n$ is composite, write $n=ab$ with $2\le a,b<n$. By the minimality of $n$, both $a$ and $b$ are products of primes. Write $a=p_1\cdots p_r$ and $b=q_1\cdots q_s$. Then

$$
n=ab=p_1\cdots p_rq_1\cdots q_s,
$$

so $n$ is a product of primes, again a contradiction.

These cases exhaust the possibilities for $n\ge2$. Therefore no counterexample exists. **Q.E.D.**

One can instead use strong induction: 2 is prime, and the induction step uses the same prime/composite split. The claim can include $n=1$ if an empty product is allowed and defined to equal 1; 1 itself is not prime.

## Problem 2

**Proof (strong induction, then cases).** For $n=0$, the formula gives $0\cdot2^{-1}=0=s_0$. For $n=1$, it gives $1\cdot2^0=1=s_1$.

Fix $n\ge2$ and assume the formula holds for every integer $j$ with $0\le j<n$. In particular, it holds at $n-1$ and $n-2$. Therefore

$$
\begin{aligned}
s_n&=4(s_{n-1}-s_{n-2})\\
&=4\bigl((n-1)2^{n-2}-(n-2)2^{n-3}\bigr)\\
&=2^{n-1}\bigl(2(n-1)-(n-2)\bigr)\\
&=n2^{n-1}.
\end{aligned}
$$

The formula holds for all $n\ge0$ by strong induction.

For the parity claim, split into three cases. At $n=0$, $s_0=0$ is even. At $n=1$, $s_1=1$ is odd. At $n\ge2$, the formula gives $s_n=2(n2^{n-2})$, with $n2^{n-2}$ an integer, so $s_n$ is even. Thus $s_n$ is odd exactly when $n=1$. **Q.E.D.**
