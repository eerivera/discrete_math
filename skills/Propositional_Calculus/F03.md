# Skill Description

Ability to translate English statements into Propositional Formulas and to translate Propositional formulas into plain English.

---

# Sample Problems

Each practice exam problem gives four propositions and asks for two translations in each direction. Use only the given propositions and the connectives $\neg$, $\wedge$, $\vee$, $\oplus$, $\rightarrow$, and $\leftrightarrow$.

## Practice Exam Problem 1

Assume a program has two functions and operates at either high or low load. Let:

* $E1$: function 1 throws an error;
* $E2$: function 2 throws an error;
* $H$: the load is high; and
* $C$: the program crashes.

Translate the following into propositional logic.

1. The program crashes if the load is high and at least one of the functions throws an error.
2. If the program crashes, then exactly one of the two functions throws an error.

Translate the following into plain English.

3. $(E1\vee E2)\rightarrow C$
4. $(E1\rightarrow H)\wedge(E2\rightarrow C)$

## Practice Exam Problem 2

Let:

* $S$: the shift key is pressed;
* $X$: the X key is pressed;
* $E$: the form is in edit mode; and
* $A$: an alert box pops up.

Translate the following into propositional logic.

1. If the X key is pressed and the form is not in edit mode, then an alert box pops up.
2. The form is in edit mode only if the shift key and the X key are both pressed.

Translate the following into plain English.

3. $A\rightarrow(E\wedge X\wedge S)$
4. $(E\wedge X)\leftrightarrow(S\oplus A)$

# Tutorial

# Practice Converting English into Propositional Calculus

Converting between English and Propositional Calculus can be challenging because of the degree to which
English is an ambiguous language. Once you have specified the propositions, logical formula involving those
symbols are completely unambiguous, but the conversion of such a formula to English, or the translation from
English in the Propositional Calculus is more of an art than a science. In this tutorial we will just go over an example
and then give you several problems to practice on...

## Propositions for the problems
Let E1, E2, H, and C be as in Practice Exam Problem 1 above.
```
E1: function 1 throws an error
E2: function 2 throws an error
H: the load is high
C: the program crashes
```

Let's translate the following English statements to propositional logic using only the logical connectives 
```
   NOT, AND, XOR, OR, IMPLIES, and IFF
```
and the four propositions above (E1,E2,H,C)

To avoid ambiguity, the examples here use parentheses to show the intended grouping.
Negation applies only to the formula immediately following it unless parentheses extend
its scope. Because AND and OR are associative, a sequence using only AND or only OR may
be written without internal parentheses; for example, $A \vee B \vee C$ and
$A \wedge B \wedge C$. When different binary operators are mixed, we use parentheses
rather than relying on precedence or associativity conventions.

Now let's translate ...

A. Both functions throw an error

**Answer:**  $E1 \wedge E2$   <br>  ```E1 AND E2```


B. If the load is high then at least one of the functions throws an error

**Answer:** $H \rightarrow (E1 \vee E2)$   <br> ```H IMPLIES ( E1 OR E2)```

and we can translate from logic to English

C.  Translate to English: $(E1 \wedge H) \rightarrow (E2 \wedge C)$

**Answer:** 
If function 1 throws an error and the load is high, then function 2 throws an error and the system crashes!

D. Translate to English: $\neg C \rightarrow \neg (E1 \vee E2)$

**Answer:**
If the system doesn't crash then neither function 1 nor function 2 throws an error.

E. Translate to English: $C \rightarrow (E1 \vee (E2 \wedge H))$

**Answer:** 
if the system crashes then either function 1 throws an error, or function 2 throws an error and the load is high.

## Additional worked translations

These shorter drills and longer examples support the exam practice above. Each exam problem uses the two-translations-in-each-direction format.

### Program examples

Use the propositions from Practice Exam Problem 1.

* Two things are true: (1) If the load is high the function 1 throws an error, and (2) if the load is low then the program crashes only if function 2 throws an error

**Answer:**
$(H \rightarrow E1) \wedge (\neg H \rightarrow (C \rightarrow E2))$

* The program keeps running (i.e. doesn't crash) only if both functions work correctly (i.e. neither function throws an error)

**Answer:**
$\neg C \rightarrow \neg(E1 \vee E2)$

* If the load is low, then the program crashes only if both functions throw an error

**Answer:** 
$\neg H \rightarrow (C \rightarrow (E1\wedge E2))$

* The program crashes if and only if function 1 throws an error when the load is high and function 2 throws an error when the load is low

**Answer:** 
$C \leftrightarrow ((H\rightarrow E1) \wedge (\neg H \rightarrow E2))$

* $\neg H \rightarrow \neg C$

**Answer:**
if the load is low then the system won't crash.

### Keyboard examples

Use the propositions from Practice Exam Problem 2.

* the shift key and the X key are both pressed

**Answer:** 
$S \wedge X$

* the alert box pops up only if the shift key is pressed

**Answer:**
$A \rightarrow S$

* the alert box pops up when an X is typed if and only if the form is not in edit mode

**Answer:**
$(X \rightarrow A) \leftrightarrow \neg E$

* Either the shift key is pressed or the x key is pressed, but not both

**Answer:**
$S \oplus X$

* if the alert box pops up when the X key is pressed, then the form is not in edit mode

**Answer:**
$(X \rightarrow A) \rightarrow \neg E$

* $\neg E \wedge \neg A$

**Answer:**
The form is not in edit mode and the alert box does not pop up.

# Answers

## Practice Exam Problem 1

1. $(H\wedge(E1\vee E2))\rightarrow C$
2. $C\rightarrow(E1\oplus E2)$
3. If at least one of the two functions throws an error, then the program crashes.
4. If function 1 throws an error, then the load is high, and if function 2 throws an error, then the program crashes.

## Practice Exam Problem 2

1. $(X\wedge\neg E)\rightarrow A$
2. $E\rightarrow(S\wedge X)$
3. If an alert box pops up, then the form is in edit mode and both the X key and the shift key are pressed.
4. The form is in edit mode and the X key is pressed if and only if exactly one of the following happens: the shift key is pressed, or an alert box pops up.
