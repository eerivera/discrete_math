# Skill Description

Ability to read and use function notation, evaluate functions given by tables, formulas, or cases, and compute images and inverse images of subsets. Distinguish a function's domain, codomain, range, and inputs where it is defined.

---

# Sample Problems

Show how you obtain each image or inverse image. List each element of a set exactly once. For partial functions, use only inputs where the function is defined; an undefined value is not an output.

## Practice Exam Problem 1

Let $A=\lbrace r,s,t,u,v\rbrace$, $B=\lbrace 0,1,2,3,4,5\rbrace$, and $f:A\rightarrow B$ be defined by the complete table

| $x$ | $r$ | $s$ | $t$ | $u$ | $v$ |
| --- | --- | --- | --- | --- | --- |
| $f(x)$ | 4 | 1 | 4 | 0 | 3 |

1. Find $f(\lbrace r,t,v\rbrace)$.
2. Find $f^{-1}(\lbrace 0,2,4\rbrace)$.

## Practice Exam Problem 2

Let $C=\lbrace a,b,c,d,e,f\rbrace$ and $D=\lbrace p,q,r,s,t\rbrace$. A partial function $g:C\rightarrow D$ has exactly these defined values:

$$
g(a)=q,\quad g(c)=s,\quad g(d)=q,\quad g(f)=p.
$$

1. Find $g(\lbrace a,b,d,f\rbrace)$.
2. Find $g^{-1}(\lbrace q,r,s\rbrace)$.

## Practice Exam Problem 3

Let $E=\lbrace -2,-1,0,1,2\rbrace$, $F=\lbrace 0,1,2,4,6,9\rbrace$, and $h:E\rightarrow F$ be defined by $h(x)=(x+1)^2$.

1. Find $h(E)$.
2. Find $h^{-1}(\lbrace 0,2,9\rbrace)$.

## Further Practice

1. Let $k:\mathbb Z\rightarrow\mathbb Z$ be defined by $k(n)=n/2$ when $n$ is even and $k(n)=3n+1$ when $n$ is odd. Find $k(-3)$, $k(4)$, $k(\lbrace -2,-1,0,1,2\rbrace)$, and $k^{-1}(\lbrace 1,4\rbrace)$.
2. Let $m:\mathbb R\rightarrow\mathbb R$ be $m(x)=3x-2$. Find $m([1,3])$ and $m^{-1}([1,4])$. If instead the stated domain is $\mathbb Z$, find its range and the inverse image of $\lbrace 1,4\rbrace$.
3. Can a function table assign both $f(a)=1$ and $f(a)=2$? Can it assign both $f(a)=1$ and $f(b)=1$ for distinct inputs? Explain.

# Tutorial

## Domain, codomain, and values

The notation $f:A\rightarrow B$ specifies an input set $A$, the **domain**, and an output set $B$, the **codomain**. A **total function** assigns exactly one value $f(a)\in B$ to every $a\in A$. Different inputs may have the same value, but one input cannot have two different values.

The course also allows **partial functions**: some inputs in the stated domain have no assigned value. Write $D_f\subseteq A$ for the set of inputs where $f$ is defined. Total means $D_f=A$. In this unit an arrow may describe a partial function when that is stated explicitly; otherwise assume the function is total.

For example, $r(x)=\sqrt{x}$ with stated domain and codomain $\mathbb R$ is partial because it has no real value at negative inputs. Restricting the domain to $[0,\infty)$ makes it total. A formula must also produce values in its stated codomain: $x\mapsto x-1$ is total from $\mathbb Z$ to $\mathbb Z$, but does not define a total function from $\mathbb N$ to $\mathbb N$ since $0-1\notin\mathbb N$.

## Ways to define functions

* A **table** gives the output for each listed input. If a partial table is declared complete, unlisted inputs have no value.
* A **formula**, such as $f(x)=x^2+1$, must be used with a stated domain and codomain.
* A **verbal rule**, such as “$p(n)$ is the $n$th prime,” gives a function for positive integer inputs.
* A **definition by cases** selects a rule according to the input. For example, absolute value on $\mathbb R$ is

$$
a(x)=\begin{cases}
x &\text{if }x\geq 0,\\
-x &\text{if }x<0.
\end{cases}
$$

Check the condition before substituting. Here the cases cover every real input and give exactly one output. If cases overlap, their outputs must agree on the overlap.

## Images and range

For $S\subseteq A$, its **image** is the set of outputs obtained from inputs in $S$. For a total function,

$$
f(S)=\lbrace f(x)\mid x\in S\rbrace.
$$

For a partial function, use $S\cap D_f$ in place of $S$. An undefined value contributes nothing. If several inputs give the same output, list that output once. For instance, if $j(a)=2$, $j(b)=2$, and $j(c)=5$, then $j(\lbrace a,b,c\rbrace)=\lbrace 2,5\rbrace$.

The **range** is $f(A)$, the set of outputs actually reached. It is a subset of the codomain and may be smaller. The induced image map is sometimes written $f_*:\mathcal P(A)\rightarrow\mathcal P(B)$, where $f_*(S)=f(S)$ and $\mathcal P(A)=2^A$ is the power set.

The parentheses are used in two ways: $f(a)$ is a value at one input, whereas $f(S)$ is the image of a subset. When inputs themselves are sets, use the declared types to distinguish these meanings. For example, a function $H:\mathcal P(\mathbb N)\rightarrow\mathbb N$ takes a whole set as one input.

## Inverse images

For $T\subseteq B$, the **inverse image** or **preimage** is

$$
f^{-1}(T)=\lbrace x\in D_f\mid f(x)\in T\rbrace.
$$

For total functions, $D_f=A$. Scan every defined input and keep exactly those whose outputs lie in $T$. Keep all inputs that work, even when they share an output. A target value that is never reached contributes no inputs.

The inverse-image map has direction

$$
f^{-1}:\mathcal P(B)\rightarrow\mathcal P(A).
$$

This notation does **not** require an inverse function. A many-to-one function still has inverse images of sets. Write $f^{-1}(\lbrace b\rbrace)$ when asking for all inputs mapping to one value $b$; the [additional notes](../../notes/math_data_types/functions.md#inverse-functions) explain when an inverse function exists.

## A method for calculations

First identify the input and output types. Evaluate every required input, using the correct case and checking whether the value is defined. For an image, collect outputs; for an inverse image, collect inputs. Finally check that the result is a subset of the correct set.

For example, if $s:\mathbb R\rightarrow\mathbb R$ is $s(x)=2x+3$, then $s([0,2])=[3,7]$. To find $s^{-1}([3,7])$, solve $3\leq 2x+3\leq 7$, giving $[0,2]$. With an integer domain, only integer solutions would be allowed.

# Answers

## Practice Exam Problem 1

1. The outputs at $r,t,v$ are $4,4,3$, so $f(\lbrace r,t,v\rbrace)=\lbrace 3,4\rbrace$.
2. The inputs $r,t$ map to 4 and $u$ maps to 0. Nothing maps to 2, so $f^{-1}(\lbrace 0,2,4\rbrace)=\lbrace r,t,u\rbrace$.

## Practice Exam Problem 2

1. The defined outputs are $g(a)=q$, $g(d)=q$, and $g(f)=p$. There is no value at $b$, so the image is $\lbrace p,q\rbrace$.
2. The inputs $a,d$ map to $q$ and $c$ maps to $s$. Nothing maps to $r$, so the inverse image is $\lbrace a,c,d\rbrace$.

## Practice Exam Problem 3

1. The table is

| $x$ | $-2$ | $-1$ | $0$ | $1$ | $2$ |
| --- | --- | --- | --- | --- | --- |
| $h(x)$ | 1 | 0 | 1 | 4 | 9 |

Thus $h(E)=\lbrace 0,1,4,9\rbrace$.

2. The input $-1$ maps to 0 and 2 maps to 9. Nothing maps to 2, so $h^{-1}(\lbrace 0,2,9\rbrace)=\lbrace -1,2\rbrace$.

## Further Practice

1. Since $-3$ is odd, $k(-3)=-8$; since 4 is even, $k(4)=2$. The outputs at $-2,-1,0,1,2$ are $-1,-2,0,4,1$, so the image is $\lbrace -2,-1,0,1,4\rbrace$. For the inverse image, the even branch gives $n=2$ or $n=8$, and the odd branch gives $n=0$ or $n=1$; only 1 satisfies the odd condition. Thus $k^{-1}(\lbrace 1,4\rbrace)=\lbrace 1,2,8\rbrace$.
2. The image is $[1,7]$. Solving $1\leq3x-2\leq4$ gives the inverse image $[1,2]$. On $\mathbb Z$, the range is $\lbrace 3n-2\mid n\in\mathbb Z\rbrace$, and the inverse image of $\lbrace 1,4\rbrace$ is $\lbrace 1,2\rbrace$.
3. The first assignment is invalid because a single input would have two outputs. The second is valid: functions may send distinct inputs to the same output.
