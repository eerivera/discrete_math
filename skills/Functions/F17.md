# Skill Description

Ability to decide and justify whether a function is total, injective, surjective, or bijective. Give precise definitions and counterexamples, and explain how the domain, codomain, and restrictions affect these properties. The broader skill also includes proofs about compositions and inverses and the construction of bijections.

---

# Sample Problems

For every classification, explain each property separately. Identify an undefined input to disprove totality, an unreached codomain element to disprove surjectivity, or two distinct inputs with the same defined output to disprove injectivity. Use the partial-function convention explained in the tutorial.

## Practice Exam Problem 1

Let $A=\lbrace 0,1,2,3,4,5,6\rbrace$ and $B=\lbrace p,q,r,s,t\rbrace$. A partial function $f:A\rightarrow B$ has exactly these defined values:

$$
f(0)=r,\quad f(1)=p,\quad f(3)=r,\quad f(4)=t,\quad f(6)=q.
$$

For each function, state whether it is total, surjective, and injective, and briefly justify each answer.

1. The function $f:A\rightarrow B$ above.
2. The restriction $g:\lbrace 0,1,4,6\rbrace\rightarrow\lbrace p,q,r,t\rbrace$, keeping the values of $f$ at those inputs.
3. The restriction $h:\lbrace 1,2,4\rbrace\rightarrow\lbrace p,t\rbrace$, keeping the defined values of $f$ and remaining undefined at 2.

### 2. Precise definitions

For a total function $u:X\rightarrow Y$, define each term precisely.

1. Injective.
2. Surjective.

## Practice Exam Problem 2

### 1. Classification

For each function, state whether it is total, surjective, and injective, and briefly justify each answer.

1. Bijective.

Let $X=\lbrace a,b,c,d\rbrace$ and $Y=\lbrace 1,2,3,4,5\rbrace$. A total function $f:X\rightarrow Y$ is given by

f(a)=2,\quad f(b)=5,\quad f(c)=2,\quad f(d)=4.

For each function, state whether it is total, surjective, and injective, and briefly justify each answer.

1. The function $f:X\rightarrow Y$ above.

## Further Practice

Use the definitions of injectivity, surjectivity, images, and inverse images to prove the following statements. State your assumptions and explain each step. Try writing your own proofs before comparing them with the worked answers.

1. Let $g:A\rightarrow B$ and $f:B\rightarrow C$ be total. Prove each statement: if both are injective, then $f\circ g$ is injective; if both are surjective, then $f\circ g$ is surjective; if $f\circ g$ is injective, then $g$ is injective; if $f\circ g$ is surjective, then $f$ is surjective. Give counterexamples to the other two converse claims: that injectivity of the composition forces $f$ to be injective, or that surjectivity of the composition forces $g$ to be surjective.
2. Let $f:A\rightarrow B$ be total and $T\subseteq B$. Prove $f(f^{-1}(T))=T\cap f(A)$. Deduce when this equals $T$, and when it equals $T$ for every $T\subseteq B$. Give a counterexample to the claim that it always equals $T$.
3. For total $f:A\rightarrow B$ and $S\subseteq A$, prove $S\subseteq f^{-1}(f(S))$. Prove equality holds for every $S\subseteq A$ if and only if $f$ is injective.

# Tutorial

## Check the stated sets first

A formula alone does not determine injectivity or surjectivity. The domain controls which inputs can collide; the codomain controls which outputs must be reached. Restricting the domain removes inputs. Changing the codomain changes the target set, and all defined outputs must still belong to it.

For example, $u(n)=2n$ from $\mathbb N$ to $\mathbb N$ is total and injective, but misses 1. The same rule from $\mathbb N$ to the even natural numbers is bijective.

## Total and partial functions

Write $D_f$ for the subset of the stated domain $A$ where $f$ has a defined value. The function is **total** if $D_f=A$ and **partial but not total** otherwise. Every defined input must have exactly one output in the codomain $B$.

For a partial function, test injectivity only on $D_f$, and test surjectivity by whether its defined values reach every member of $B$. Thus totality, injectivity, and surjectivity are separate questions.

A **bijection between $A$ and $B$** is a total function that is both injective and surjective. A partial function whose defined values are one-to-one and onto $B$ gives a bijection from $D_f$ to $B$, but not from all of $A$ to $B$. For example, the partial $h$ in Practice Exam Problem 1 has $D_h=\lbrace 1,4\rbrace$. It gives a bijection from that set to $\lbrace p,t\rbrace$, but not from its full stated domain $\lbrace 1,2,4\rbrace$.

## Injectivity

A function is **injective**, **one-to-one**, or **1–1** if distinct defined inputs have distinct outputs. Equivalently,

$$
\forall a_1\in D_f . \forall a_2\in D_f . (f(a_1)=f(a_2)\rightarrow a_1=a_2).
$$

For a total function, replace $D_f$ by $A$. We sometimes write $f:A\hookrightarrow B$ for an injection.

To prove injectivity, start with arbitrary defined inputs $a_1,a_2$ and assume $f(a_1)=f(a_2)$. Use the rule and the domain to deduce $a_1=a_2$. For $f(x)=3x-4$ on $\mathbb R$, equality of outputs gives $3a_1-4=3a_2-4$, hence $a_1=a_2$.

To disprove injectivity, exhibit a **collision**: two distinct defined inputs with equal outputs. Its negation is

$$
\exists a_1\in D_f . \exists a_2\in D_f . (a_1\ne a_2\wedge f(a_1)=f(a_2)).
$$

## Surjectivity

A function is **surjective** or **onto** if its range equals its codomain:

$$
\forall b\in B . \exists a\in D_f . f(a)=b.
$$

We sometimes write $f:A\twoheadrightarrow B$ for a surjection. For a total function, replace $D_f$ by $A$.

To prove surjectivity, take an arbitrary target $b\in B$, find a preimage $a$, check $a\in D_f$, and verify $f(a)=b$. For $f:\mathbb R\rightarrow\mathbb R$, $f(x)=3x-4$, use $a=(b+4)/3$.

To disprove surjectivity, give one target with no preimage. The negation is

$$
\exists b\in B . \forall a\in D_f . f(a)\ne b.
$$

Solving an equation is not enough if the solution lies outside the domain. For example, $x+2=1$ has solution $x=-1$, but that input is unavailable in $\mathbb Q^+$.

## Bijections and combined conditions

For total functions, **bijective** means both injective and surjective: every target has exactly one preimage. This is a **one-to-one correspondence** between the two sets. In the setting of sets alone, an isomorphism means such a bijection; other mathematical structures may require it to preserve additional structure.

To describe a combination, join the corresponding conditions with “and.” For example, a total $f:A\rightarrow B$ is injective but not surjective exactly when

$$
\left(\forall a_1\in A . \forall a_2\in A . (f(a_1)=f(a_2)\rightarrow a_1=a_2)\right)
\wedge
\left(\exists b\in B . \forall a\in A . f(a)\ne b\right).
$$

The parentheses end each quantifier's scope before the outer conjunction. Use “neither injective nor surjective” to mean both properties fail; give a collision **and** an unreached target.

## Restrictions and a classification checklist

A restriction $f|_S$ keeps the values of $f$ at inputs in $S\subseteq A$. A previously undefined input remains undefined. If a new codomain is stated, check that it contains every retained output.

For a finite table, compare the defined inputs with the domain, compare the range with the codomain, and look for repeated output values at distinct inputs. For formulas, check definedness and output type, solve equality of outputs, and test an arbitrary target. State a reason for each result; a label alone is not a justification.

# Answers

## Practice Exam Problem 1

### 1. Classification

1. $f$ is **not total**, since 2 and 5 have no values; **not surjective**, since $s$ is never reached; and **not injective**, since $f(0)=f(3)=r$ with $0\ne3$.
2. $g$ is **total**, since all four inputs have values; **surjective**, since its range is the stated codomain $\lbrace p,q,r,t\rbrace$; and **injective**, since the outputs $r,p,t,q$ are distinct.
3. $h$ is **not total**, since it is undefined at 2. It is **surjective**, since $h(1)=p$ and $h(4)=t$ reach the entire codomain, and **injective**, since its two defined outputs differ.

### 2. Precise definitions

1. Injectivity means $\forall x_1\in X . \forall x_2\in X . (u(x_1)=u(x_2)\rightarrow x_1=x_2)$.
2. Surjectivity means $\forall y\in Y . \exists x\in X . u(x)=y$.

## Practice Exam Problem 2

### 1. Classification

1. $r$ is **total**, since $n(n+1)$ is a natural number for every $n\in\mathbb N$. If $n(n+1)=m(m+1)$, then $(n-m)(n+m+1)=0$. Since $n+m+1>0$, this forces $n=m$, proving **injectivity**. The target 1 is missed: $r(0)=0$, and for $n\geq1$ we have $r(n)\geq2$. Thus $r$ is **not surjective**.
2. Squaring a positive rational and dividing by 2 gives a positive rational, so $k$ is **total**. If $x_1^2/2=x_2^2/2$, then positivity forces $x_1=x_2$, proving **injectivity**. The target 1 would require $x=\sqrt2$, which is not rational, so $k$ is **not surjective**. The [irrationality proof in F09](../Proof_Techniques/F09.md#interesting-application) justifies that missing preimage.
3. The formula for $\ell$ is real and defined for every real input, so it is **total**. Equality $(x_1+1)^3-4=(x_2+1)^3-4$ implies $x_1=x_2$, proving **injectivity**. Every real target $y$ has real preimage $x=\sqrt[3]{y+4}-1$, proving **surjectivity**.

### 2. Precise definitions

1. A total function is bijective if it is both injective and surjective:

$$
\left(\forall x_1\in X . \forall x_2\in X . (u(x_1)=u(x_2)\rightarrow x_1=x_2)\right)
\wedge
\left(\forall y\in Y . \exists x\in X . u(x)=y\right).
$$

2. Neither surjective nor injective means that both properties fail: some target is missed, and two distinct inputs collide.

$$
\left(\exists y\in Y . \forall x\in X . u(x)\ne y\right)
\wedge
\left(\exists x_1\in X . \exists x_2\in X . (x_1\ne x_2\wedge u(x_1)=u(x_2))\right).
$$

## Practice Exam Problem 3

### 1. Classification

1. $f$ is **total** because every input has a value. It is **not surjective**, since 1 and 3 are missed, and **not injective**, since $f(a)=f(c)=2$.
2. $g$ is **total and injective**: its three inputs map to the distinct outputs $5,2,4$. It is **not surjective**, since its codomain still contains 1 and 3.
3. $h$ is **total and surjective**, since its range is exactly the new codomain. It is **not injective**, since the collision at $a,c$ remains.

### 2. Precise definitions

1. Injective but not surjective means equal outputs force equal inputs, and some target is missed:

$$
\left(\forall x_1\in X . \forall x_2\in X . (u(x_1)=u(x_2)\rightarrow x_1=x_2)\right)
\wedge
\left(\exists y\in Y . \forall x\in X . u(x)\ne y\right).
$$

2. Surjective but not injective means every target is reached, and two distinct inputs collide:

$$
\left(\forall y\in Y . \exists x\in X . u(x)=y\right)
\wedge
\left(\exists x_1\in X . \exists x_2\in X . (x_1\ne x_2\wedge u(x_1)=u(x_2))\right).
$$

## Further Practice

### 1. Composition properties

Assume throughout that $g:A\rightarrow B$ and $f:B\rightarrow C$ are total.

**Two injections compose to an injection.** Let $a_1,a_2\in A$ and suppose $f(g(a_1))=f(g(a_2))$. Injectivity of $f$ gives $g(a_1)=g(a_2)$, and injectivity of $g$ gives $a_1=a_2$. **Q.E.D.**

**Two surjections compose to a surjection.** Fix any $c\in C$. Surjectivity of $f$ supplies $b\in B$ with $f(b)=c$. Surjectivity of $g$ supplies $a\in A$ with $g(a)=b$. Hence $(f\circ g)(a)=f(b)=c$. Every target has a preimage. **Q.E.D.**

**An injective composition forces the inner function to be injective.** Suppose $g(a_1)=g(a_2)$. Applying $f$ gives $(f\circ g)(a_1)=(f\circ g)(a_2)$. Injectivity of the composition gives $a_1=a_2$. **Q.E.D.**

**A surjective composition forces the outer function to be surjective.** Fix any $c\in C$. There is an $a\in A$ with $f(g(a))=c$. Since $g(a)\in B$, this is a preimage of $c$ under $f$. **Q.E.D.**

**The other factors need not have the property.** Take $A=C=\lbrace 0\rbrace$ and $B=\lbrace 0,1\rbrace$, with $g(0)=0$ and $f(0)=f(1)=0$. The composition is the identity on $\lbrace 0\rbrace$, so it is both injective and surjective. But $f$ is not injective, and $g$ is not surjective.

### 2. Image of an inverse image

Fix $b\in B$. By the definitions,

$$
\begin{aligned}
b\in f(f^{-1}(T))
&\leftrightarrow (\exists a\in A . (f(a)\in T\wedge f(a)=b))\\
&\leftrightarrow (b\in T\wedge b\in f(A))\\
&\leftrightarrow b\in T\cap f(A).
\end{aligned}
$$

The sets have exactly the same elements. Thus $f(f^{-1}(T))=T$ for a particular $T$ precisely when $T\subseteq f(A)$. It holds for every subset $T$ of the codomain if and only if $f(A)=B$, that is, $f$ is surjective. **Q.E.D.**

For a counterexample without surjectivity, take $A=\lbrace a\rbrace$, $B=\lbrace 0,1\rbrace$, $f(a)=0$, and $T=\lbrace 1\rbrace$. Then $f^{-1}(T)=\emptyset$ and $f(\emptyset)=\emptyset\ne T$.

### 3. Inverse image of an image

If $a\in S$, then $f(a)\in f(S)$, so $a\in f^{-1}(f(S))$. This proves the inclusion for every total function.

If $f$ is injective and $a\in f^{-1}(f(S))$, then $f(a)=f(s)$ for some $s\in S$. Injectivity gives $a=s$, hence $a\in S$. Together with the first inclusion this proves equality.

Conversely, suppose equality holds for every $S\subseteq A$. If $f(a_1)=f(a_2)$, use $S=\lbrace a_1\rbrace$. Then $a_2\in f^{-1}(f(S))=S$, forcing $a_2=a_1$. Thus $f$ is injective. **Q.E.D.**
