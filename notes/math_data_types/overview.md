# Overview of Mathematical Data Types

Discrete Math deals with a number of Mathematical Data Types

The ones we will discuss here are:
* [sets](sets.md)
* [sequences](sequences.md)
* [functions](functions.md)
* [relations](relations.md)

## Sets: tutorials and practice

The [sets unit](../../skills/Sets/README.md) connects the older course notes to the current skill pages:

* [F12: Set notation and comprehensions](../../skills/Sets/F12.md) develops the notation introduced in [Sets](sets.md).
* [F13: Set algebra](../../skills/Sets/F13.md) expands [Sets and logic](setsAndLogic.md) with laws, proofs, and counterexamples.
* [F14: Constructed sets and cardinality](../../skills/Sets/F14.md) develops nested constructions from [Products and sequences](sequences.md), with further-reading links for disjoint unions and counting proofs.

## Functions: tutorials and practice

The [Functions unit](../../skills/Functions/README.md) connects the definitions in [Functions](functions.md) with the current skill pages:

* [F15: Function notation](../../skills/Functions/F15.md) develops values, images, and inverse images, including partial functions.
* [F16: Composition](../../skills/Functions/F16.md) develops numeric, tuple, and finite-set compositions and general formulas.
* [F17: Function properties](../../skills/Functions/F17.md) develops classifications, quantified definitions, and proofs about composition, images, and inverse images.

Products of functions, inverse-function constructions, and additional bijection constructions are in the linked function notes.
